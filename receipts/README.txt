RECEIPTS / SLIPS — FOLDER STRUCTURE
====================================

Save every payment receipt or slip here, organized by:

    receipts / <category> / <year> / <month> / <descriptive-filename>

Categories:
    electricity/   MEA or PEA electricity bills + payment slips
    water/         water bills + slips
    common-fee/    common-area / maintenance fee receipts
    other/         anything else (repairs, cleaning, misc.)

Year  = 4 digits (e.g. 2026)
Month = 2 digits (e.g. 09 for September)

Example paths:
    receipts/electricity/2026/09/electricity_ref123456_2026-09.jpg
    receipts/common-fee/2026/09/house-12-3_rc-2026-0001.jpg
    receipts/water/2026/09/water_meter7788_2026-09.jpg

HOW IT WORKS WITH THE APP
-------------------------
In the VillageMan app, when you add a Utility Bill (or record a
payment), click "Suggest path" — the app generates the exact folder + file
name to use, following the structure above. Save your scanned/downloaded
receipt file at that path in Google Drive, then keep the path stored in the
app. The app links to the file; it never stores the image itself.

This keeps the app's data lightweight and your receipts neatly filed and
shareable via Google Drive with normal view-only permissions.
